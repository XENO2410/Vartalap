# Intranet Guide: Corporate Directory

## What It Is

The Corporate Directory provides people and team contact details.

## Getting There

Open the intranet home page and select the tile from the top navigation.

## Tips

Use exact terms for search.

Check the publication date before relying on content.

## Support

Content queries route to Corporate Communications; access issues to the IT helpdesk.
